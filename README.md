# Boston House Price Predictor 🏡

## 📖 Project Overview
This Machine Learning project predicts housing prices in Boston based on sociological and economic data. By analyzing factors such as the number of rooms, crime rates, and pupil-teacher ratios, the model identifies which characteristics most strongly influence property value.

The project consists of two parts:
1.  **Python Analysis:** A script that performs Exploratory Data Analysis (EDA) and trains a Linear Regression model.
2.  **Web Application:** A user-friendly React website that allows users to interact with the model's logic in real-time.

## 📂 File Structure
* **`boston.csv`**: The original dataset containing housing metrics.
* **`housing_analysis.py`**: The Python source code for data preprocessing, model training, and evaluation.
* **`index.html`**: The frontend application. It is a standalone file containing HTML, CSS (Tailwind), and React JavaScript.

## 🛠️ Technologies Used
* **Python** (Pandas, Scikit-Learn, NumPy)
* **Web** (HTML5, React.js, Tailwind CSS)

## 🚀 How to Run
1.  **Run the Model:**
    ```bash
    python housing_analysis.py
    ```
2.  **Launch the App:**
    Simply double-click `index.html`. No server installation is required.
